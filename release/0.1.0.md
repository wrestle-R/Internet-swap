# Internet Swap 0.1.0

First Linux preview. A small Tauri window, a background Wi-Fi service and a matching Next.js website.

- HyprTrack’s Plum palette with persistent light/dark controls in the app and website.
- Saved, visible secured networks through NetworkManager, with no password handling in the app.
- Background internet checks, live traffic, timestamped download/upload tests and a persistent automatic-switching toggle.
- Recent measured improvements must pass repeated checks before a speed-based switch. Repeated internet failures trigger recovery. Failed candidate connections attempt to restore the previous Wi-Fi.
- Optional Hyprland sidebar controls and login startup, mirrored in the Linux and dots-hyprland customization packages.

A single Wi-Fi adapter cannot test other networks without leaving its current connection. Switching can interrupt active requests; this does not combine bandwidth or guarantee that downloads and chat sessions survive. Speed tests consume data. USB tethering is outside selection logic.

Linux x86_64 only. NetworkManager, curl and coreutils are required on the host. The AppImage also needs a compatible Linux desktop and FUSE support (or AppImage extraction). Debian packages declare runtime dependencies. Automatic app updates are not included.
