# Internet Swap 0.1.1

Linux preview with HyprTrack’s Plum palette, saved light/dark appearance, background Wi-Fi checks and matching Hyprland sidebar controls.

This corrects an AppImage issue found during installation on Arch Linux. Bundled library paths could leak into the host’s curl and cause false internet failures. NetworkManager and curl now run without AppImage library overrides, and bundled executable paths are removed from their search path. Regression checks exercise that polluted environment.

- Saved, visible secured Wi-Fi profiles through NetworkManager; passwords stay there.
- Current traffic, timestamped download/upload tests and a persistent automatic-switching toggle.
- Speed-based switching needs recent measurements and repeated evidence of a meaningful improvement. Repeated internet failures trigger recovery; failed candidates attempt to restore the previous Wi-Fi.
- The separate Hyprland customization packages add sidebar controls, login startup and a narrow floating window.

One adapter generally joins one network at a time. Switching and alternative-network tests can interrupt active requests. This does not combine bandwidth or guarantee uninterrupted sessions. Successful speed tests use about 1.25 MiB each plus overhead. USB tethering is outside selection logic.

Linux x86_64 only. NetworkManager, curl and coreutils are required on the host. AppImage needs FUSE support or extraction; Debian packages declare runtime dependencies. No automatic app updater is included. The earlier 0.1.0 AppImage is withdrawn while this correction is verified.
